# Cursor-നും Grok Bot-നും വേണ്ടിയുള്ള Replica skills

</div>

ഒരു ആപ്പ് ചെയ്യുന്നത് പുതുതായി ഉണ്ടാക്കുന്ന പതിനൊന്ന് skill-കൾ, അവയുടെ ക്രമം പിടിച്ചുനിർത്തുന്ന ഒരു skill ആയ `replica`. സൗജന്യം, MIT. Python 3.8-ഉം സ്റ്റാൻഡേർഡ് ലൈബ്രറിയും ഒഴികെ ഇൻസ്റ്റാൾ ചെയ്യാനൊന്നുമില്ല.

## പന്ത്രണ്ട്

| skill | ചെയ്യുന്നത് |
| --- | --- |
| `replica` | ക്രമം, ഓരോ ഘട്ടവും വായിക്കുകയും എഴുതുകയും ചെയ്യുന്ന ഫയലുകൾ, അടുത്തതായി ഏത് ഘട്ടം ഓടിക്കണം. |
| `replica-recon` | സ്ക്രീനുകൾ, ഒഴുക്കുകൾ, ഭാഗങ്ങൾ, ഡാറ്റ മോഡൽ, ഫീച്ചർ പട്ടിക. പൊതുപേജുകൾ, സ്ക്രീൻഷോട്ടുകൾ, സ്റ്റോർ പേജുകൾ, നിങ്ങളുടെ അക്കൗണ്ട്. |
| `replica-architect` | സ്റ്റാക്ക്, ഡാറ്റാബേസ് സ്കീമ, API. |
| `replica-design` | നിറത്തിന്റെ റോളുകൾ, ടൈപ്പ്, ഇടം, ഭാഗങ്ങൾ, ടോക്കണുകളായി, നിങ്ങളുടെ സ്വന്തം അസറ്റുകളോടെ. |
| `replica-build` | ആപ്പ്, സ്ക്രീൻ സ്ക്രീനായി, രഹസ്യാന്വേഷണ മാപ്പിൽ നിന്ന്. |
| `replica-backend` | പ്രവേശനം, ഡാറ്റാബേസ്, പണമടയ്ക്കൽ, ബന്ധിപ്പിക്കലുകൾ. |
| `replica-test` | ഓരോ ഒഴുക്കും, ക്ലിക്ക് ചെയ്തും പരീക്ഷിച്ചും. |
| `replica-diff` | ഒരു തുല്യതാ സ്കോർ, ഇനിയും കുറവുള്ളത്. |
| `replica-entrepreneur` | യഥാർത്ഥ ഉപയോക്താക്കൾ വെറുക്കുന്നത്, തിരുത്തലുകളും ഒരു സ്ഥാനകോണും ആയി. |
| `replica-brand` | നിങ്ങളുടെ പേരും ബ്രാൻഡും, പിന്നെ ബാക്കിയുള്ളതിന്റെ അടിച്ചുവാരൽ. |
| `replica-launch` | ലാൻഡിങ് പേജ്, വില, സ്റ്റോർ എഴുത്ത്. |
| `replica-deploy` | തത്സമയം, നിങ്ങളുടെ ഡൊമെയ്നിൽ, മുൻപരിശോധന കഴിഞ്ഞ ശേഷം. |

ഈ ക്രമത്തിൽ ഓടിക്കുക:

```
recon -> architect -> design -> build -> backend -> test -> diff -> entrepreneur -> brand -> launch -> deploy
```

ഒരു ലിങ്ക് പങ്കിട്ടാൽ മറ്റൊരാൾ സമയം ബുക്ക് ചെയ്യുന്ന തരം അപ്പോയിന്റ്മെന്റ് ആപ്പ് ഇങ്ങനെ പോകുന്നു.

1. **replica-recon** സഹായകേന്ദ്രം, വിലപ്പേജ്, സ്റ്റോർ പേജ്, പൊതു നടത്തങ്ങൾ എന്നിവ വായിക്കുന്നു. നിങ്ങളുടെ അക്കൗണ്ടിൽ നിങ്ങൾ ക്ലിക്ക് ചെയ്യുന്നു. പുറത്തുവരുന്നത് `replica/recon.md` ഉം `replica/features.csv` ഉം ആണ്. പങ്കാളി മാർക്കറ്റ് പരിധിക്ക് പുറത്താണ്: അത് അവരുടെ ശൃംഖലയാണ്, ഒരു ഫീച്ചറല്ല.
2. **replica-architect** വിരസമായ, കൈകാര്യം ചെയ്യപ്പെടുന്ന ഒരു സ്റ്റാക്ക് തിരഞ്ഞെടുക്കുന്നു, സ്കീമ എഴുതുന്നു (രണ്ട് അതിഥികൾ ഒരേ സ്ലോട്ട് ബുക്ക് ചെയ്യാതിരിക്കാനുള്ള നിയന്ത്രണം ഉൾപ്പെടെ), ബുക്കിങ് ഒഴുക്കിന് ചുറ്റും നിർമ്മാണം ക്രമീകരിക്കുന്നു.
3. **replica-design** സ്ക്രീൻഷോട്ടുകൾ ടോക്കണുകളായി അളക്കുന്നു: നിറ റോളുകൾ, ടൈപ്പ്, ഇടം, തീയതി തിരഞ്ഞെടുക്കൽ, സ്ലോട്ട് ബട്ടൺ. തുറന്ന ഐക്കണുകൾ, തുറന്ന ഫോണ്ട്, നിങ്ങളുടെ വാക്കുകൾ.
4. **replica-build** ഷെൽ ഉണ്ടാക്കുന്നു, പിന്നെ ബുക്കിങ് ഒഴുക്ക്, പിന്നെ ഓരോ സ്ക്രീനും അതിന്റെ അവസ്ഥകളോടെ, പോകുമ്പോൾ `features.csv` ടിക് ചെയ്യുന്നു.
5. **replica-backend** സൈൻ അപ്പ്, നിങ്ങളുടെ കീകളോടെ ദാതാവിന്റെ സ്വന്തം API വഴിയുള്ള കലണ്ടർ, ടെസ്റ്റ് മോഡിലെ പണമടയ്ക്കൽ, ഓർമ്മപ്പെടുത്തൽ മെയിൽ എന്നിവ ചേർക്കുന്നു.
6. **replica-test** ഒഴുക്കുകളിൽ നിന്ന് ഒരു പ്ലാൻ എഴുതുന്നു, സുഖപാതത്തിനും അരികുകൾക്കും അറ്റം മുതൽ അറ്റം വരെയുള്ള ടെസ്റ്റുകൾ, S1 അല്ലെങ്കിൽ S2 തുറന്ന് കിടക്കാത്തത് വരെ തീവ്രത പ്രകാരം ബഗുകൾ.
7. **replica-diff** സ്കോർ ഇടുന്നു. ഉണ്ടായിരിക്കേണ്ടത് കുറഞ്ഞാൽ പുറത്തിറക്കാനാവില്ല.
8. **replica-entrepreneur** യഥാർത്ഥ അവലോകനങ്ങൾ മാത്രം വായിക്കുന്നു. ഓരോ ഉദ്ധരണിയും നിങ്ങൾ നൽകിയ ഒരു വരിയിൽ നിന്ന് പകർത്തിയതാണ്, ആ വരിയുടെ URL-ോടെ.
9. **replica-brand** വ്യാപാരമുദ്രയും ഡൊമെയ്നും ശരിക്കും പരിശോധിച്ച ശേഷം പേരിടുന്നു, പിന്നെ ഒറിജിനലിൽ ഒന്നും ബാക്കിയാകാത്തത് വരെ മരം അടിച്ചുവാരുന്നു.
10. **replica-launch** ആ കോണിന് ചുറ്റും ലാൻഡിങ് പേജ് എഴുതുന്നു, പൊതു വിലപ്പേജിന് നേരെ വിലയിടുന്നു (വായിച്ച തീയതിയോടെ), സ്റ്റോർ എഴുത്ത് പരിശോധിക്കുന്നു.
11. **replica-deploy** മുൻപരിശോധന ഓടിക്കുന്നു, നിങ്ങൾ പോകാം എന്ന് പറയുമ്പോൾ പുറത്തിറക്കുന്നു.

ഏത് skill-ഉം തനിയെ ഓടിക്കാം. നിങ്ങൾ തുടങ്ങിയിട്ടില്ലാത്ത ഒരു ആപ്പിൽ replica-entrepreneur ഓടിക്കുന്നത്, ഉണ്ടാക്കണോ എന്ന് തീരുമാനിക്കാൻ യുക്തമായ വഴിയാണ്.

## Cursor-ന് ഇൻസ്റ്റാൾ

Cursor പ്രോജക്റ്റ് skill-കൾ `.cursor/skills/<name>/SKILL.md`-ലും `.agents/skills/<name>/SKILL.md`-ലും നിന്ന് ലോഡ് ചെയ്യുന്നു, ഉപയോക്താവിന് `~/.cursor/skills/`-ലും `~/.agents/skills/`-ലും നിന്ന്. ഫോൾഡറിന്റെ പേര് skill-ന്റെ പേരാണ്. മുന്നോട്ടുള്ള ഭാഗത്ത് `name`-ഉം `description`-ഉം വേണം, `name` ഫോൾഡറുമായി ചേരണം.

ഈ ഇൻസ്റ്റാളർ `.cursor/skills` (പ്രോജക്റ്റ്) ഉം `~/.cursor/skills` (`--global`) ഉം ഉപയോഗിക്കുന്നു. പ്രോജക്റ്റ് skill-കൾ റിപ്പോസിറ്ററിയോടൊപ്പം പോകുന്നു. `~/.cursor/skills/`-ലെ ഉപയോക്തൃ skill-കൾ Settings, Agents-ൽ Cloud Agents-നുള്ള സിങ്ക് ഓൺ ചെയ്യുന്നത് വരെ ആ യന്ത്രത്തിൽ നിൽക്കും. ഒരു റിപ്പോസിറ്ററിയുടെ ഓരോ Cloud Agent ഓട്ടത്തിലും വേണ്ട skill ആ റിപ്പോസിറ്ററിയുടെ `.cursor/skills/`-ൽ ആയിരിക്കണം.

```bash
git clone https://github.com/letmefind/replica-skill-cursor-grok.git
cd replica-skill-cursor-grok
./cursor/install.sh                  # ./.cursor/skills
./cursor/install.sh --project /path/to/app
./cursor/install.sh --global         # ~/.cursor/skills
```

വീണ്ടും ഓടിച്ചാൽ Replica ഫോൾഡറുകളും `replica-tools/`-ഉം മാറ്റിസ്ഥാപിക്കും, അവിടെയുള്ള മറ്റ് skill-കളെ തൊടില്ല.

ചാറ്റിൽ `/` ടൈപ്പ് ചെയ്ത് `replica` അല്ലെങ്കിൽ `replica-recon` തിരഞ്ഞെടുക്കുക. അത് skill-നെ ഒരു സന്ദേശത്തിൽ ചേർക്കുന്നു. സെഷൻ മുഴുവൻ നിർത്താൻ അതിനെ Custom Mode ആയി തുടങ്ങുക: macOS-ൽ Option+Enter, Windows-ൽ Alt+Enter.

ടെംപ്ലേറ്റുകൾ skill ഫോൾഡറിൽ നിൽക്കും. Python ഉപകരണങ്ങൾ ഒരു പങ്കിട്ട പകർപ്പാണ്. ഇൻസ്റ്റാൾ ചെയ്ത ശേഷം അവ skill ഫോൾഡറുകൾക്ക് അരികിലുള്ള `replica-tools/`-ൽ ആണ്. ഈ റിപ്പോസിറ്ററിയുടെ ഒരു ചെക്കൗട്ടിൽ നിന്ന് `REPLICA_HOME` ആ ചെക്കൗട്ടിലേക്ക് വെച്ചാൽ skill-കൾ അവിടത്തെ `tools/` ഉപയോഗിക്കും. Python 3.8 അല്ലെങ്കിൽ പുതിയത്. pip കൊണ്ട് ഇൻസ്റ്റാൾ ചെയ്യാനൊന്നുമില്ല.

## Grok Bot-ന് ഇൻസ്റ്റാൾ

ഇത് മുഴുവൻ സന്ദേശമായി അയയ്ക്കുക:

```
Install the Replica skills from https://github.com/letmefind/replica-skill-cursor-grok
```

അതിനു ശേഷമുള്ള ഘട്ടങ്ങൾ [grok-bot/INSTALL.md](../../grok-bot/INSTALL.md)-ൽ ഉണ്ട്. ചുരുക്കം: ഈ റിപ്പോസിറ്ററി `/home/box/replica-skill`-ലേക്ക് clone ചെയ്യുക (`REPLICA_HOME` കൊണ്ട് മാറ്റാം), `grok-bot/install.sh` ഓടിക്കുക, പിന്നെ `grok-bot/skills/*/SKILL.md`-ലെ ഓരോ ഫയലും ഒരു skill ആയി സേവ് ചെയ്യുക. പേരും വിവരണവും ഉള്ളടക്കവും അതേപടി പകർത്തുന്നു. ഒരു Grok Bot skill ആ ഒറ്റ ഫയലാണ്. ഉപകരണങ്ങളും ടെംപ്ലേറ്റുകളും ഡിസ്കിൽ നിൽക്കും, skill-കൾ അവയെ കേവല പാതയിൽ വിളിക്കും, ഉദാഹരണം `python3 "${REPLICA_HOME:-/home/box/replica-skill}/tools/parity.py"`.

ഒരു പ്രോജക്റ്റിന്റെ ഗവേഷണ കുറിപ്പുകൾ `/workspace/<project-slug>/replica/`-ൽ ആണ്. ഒരു ഘട്ടം ആപ്പ് എഴുതാൻ തുടങ്ങിയാൽ `replica/` നിങ്ങളുടെ കോഡ് റിപ്പോസിറ്ററിയിലാണ്. കോഡ് മാറ്റങ്ങൾ ആ GitHub റിപ്പോസിറ്ററിയിലെ ഒരു Cursor cloud coding agent-ന് കൈമാറുന്നു, വേണ്ട `replica/` ഫയലുകൾ ഉൾപ്പെട്ട ഒരു ജോലിയായി. സൈൻ ഇൻ, പണമടയ്ക്കൽ, ഡൊമെയ്ൻ വാങ്ങൽ, ലൈവ് കീകൾ ടൈപ്പ് ചെയ്യൽ നിങ്ങൾ തന്നെ ചെയ്യണം.

## ഉപകരണങ്ങൾ

```bash
python3 tools/imgdiff.py original.png clone.png --out diff.png
python3 tools/parity.py replica/features.csv
python3 tools/reviews.py replica/reviews.csv
python3 tools/contrast.py replica/design/tokens.json
python3 tools/sweep.py . --avoid "Original App"
python3 tools/listing.py replica/launch/listing.json
```

ഒന്നും നെറ്റ്‌വർക്ക് ഉപയോഗിക്കുന്നില്ല. `imgdiff.py` നിറമല്ല, ലേഔട്ട് താരതമ്യം ചെയ്യുന്നു, അതുകൊണ്ട് റീബ്രാൻഡ് നിങ്ങൾക്ക് എതിരായി എണ്ണില്ല. `parity.py` must, should, could എന്നിവയ്ക്ക് ഭാരം കൊടുക്കുന്നു, partial-നെ പകുതിയായി എണ്ണുന്നു, മനഃപൂർവം ഒഴിവാക്കിയ വരി സ്കോർ ചെയ്യില്ല. `reviews.py` ലിങ്കില്ലാത്ത വരി ഉപേക്ഷിക്കുന്നു. `sweep.py` ഒറിജിനലിന്റെ പേരോ ഡൊമെയ്നോ നിറങ്ങളോ മരത്തിൽ ഉള്ളിടത്തോളം പുറത്തിറക്കൽ തടയുന്നു. `listing.py` സ്റ്റോർ പരിധികൾ പരിശോധിച്ച് നിങ്ങളുടെ ലിസ്റ്റിങ്ങിൽ ഒറിജിനലിന്റെ പേര് നിരസിക്കുന്നു.

```bash
python3 -m unittest discover -s tests -v
python3 scripts/validate.py
```

## ചെറിയ അക്ഷരം

**അത് പ്രവർത്തനവും ഉപയോഗ രീതികളും പുതുതായി ഉണ്ടാക്കുന്നു, ക്ലീൻ റൂമായി.** ആപ്പ് എന്ത് ചെയ്യുന്നു, ആളുകൾ അതിലൂടെ എങ്ങനെ നടക്കുന്നു എന്ന് നോക്കി എല്ലാം പുതുതായി എഴുതുന്നു. ലക്ഷ്യത്തിന്റെ സോഴ്സ് കോഡോ സ്വകാര്യ അസറ്റുകളോ ലോഗോകളോ വ്യാപാരമുദ്രകളോ വാചകമോ സ്വകാര്യ API-കളോ അത് പകർത്തുന്നില്ല.

**വായിക്കാൻ അനുവാദമുള്ളത് മാത്രം അത് വായിക്കുന്നു.** പൊതുപേജുകളും നിങ്ങളുടെ അക്കൗണ്ടും. ലോഗിന് പിന്നിൽ ചുരണ്ടുന്നില്ല, ഒരു സൈറ്റിന്റെ നിബന്ധനകൾക്ക് എതിരാകുന്നില്ല, മറ്റൊരാളുടെ അക്കൗണ്ടിൽ കയറുന്നില്ല, പണമതിർ മറികടക്കുന്നില്ല. നിങ്ങളുടെ അക്കൗണ്ട് നിബന്ധനകൾ എതിരാളിയുണ്ടാക്കാൻ അത് ഉപയോഗിക്കുന്നത് വിലക്കുന്നുണ്ടെങ്കിൽ skill അത് പറയുകയും പൊതു ഉറവിടങ്ങളിൽ നിൽക്കുകയും ചെയ്യും.

**പുറത്തിറക്കുന്നതിന് മുമ്പ് ബ്രാൻഡ് മാറ്റുന്നു.** പുതിയ പേര്, പുതിയ നിറക്കൂട്ട്, പുതിയ ലോഗോ, പുതിയ വാക്കുകൾ. അടിച്ചുവാരൽ വൃത്തിയാകുന്നത് വരെ replica-deploy പുറത്തിറക്കില്ല.

**«ഏത് ആപ്പും ക്ലോൺ ചെയ്യുക» എന്നാൽ ഫീച്ചറുകളും ഒഴുക്കും.** ഉള്ളടക്കമോ ശൃംഖലയോ ഒരു ആപ്പ് കൈവശമുള്ള ലൈസൻസുകളോ അല്ല. ഒരു സംഗീത ആപ്പിന്റെ പ്ലെയറും പ്ലേലിസ്റ്റുകളും പങ്കിടലും പുതുതായി ഉണ്ടാക്കാം. അതിന്റെ കാറ്റലോഗ് ക്ലോൺ ചെയ്യാനാവില്ല.

**പൂർണ്ണ ക്ലോണിന്റെ വാഗ്ദാനമില്ല.** ഒരു ബുക്കിങ് ഉപകരണം ആഴ്ചകളാണ്. ഒരു സ്പ്രെഡ്ഷീറ്റ് എഞ്ചിൻ അല്ല. തുടങ്ങുന്നതിന് മുമ്പ് replica-recon വലുപ്പം പറയും, replica-diff ഒരു സംഖ്യ തരും.

**സംരംഭ skill കെട്ടിച്ചമയ്ക്കുന്നില്ല.** ഉണ്ടാക്കിയ അവലോകനങ്ങളോ ഉദ്ധരണികളോ സംഖ്യകളോ ഇല്ല. ഓരോ അവകാശവാദത്തിനും ഒരു ലിങ്ക് ഉണ്ട്, സാമ്പിൾ വലുപ്പം എഴുതിയിട്ടുണ്ട്.

**വിൽക്കുന്നതിന് മുമ്പ് പരിശോധിക്കുക.** replica-brand പട്ടികപ്പെടുത്തുന്ന വ്യാപാരമുദ്ര പരിശോധനകൾ ഓടിക്കുക, ഉപയോഗിച്ചതിന്റെ നിബന്ധനകൾ വായിക്കുക, പണം ഉൾപ്പെട്ടാൽ പുറത്തിറക്കുന്നതിന് മുമ്പ് ഒരു അഭിഭാഷകനോട് സംസാരിക്കുക. ഇത് നിയമോപദേശമല്ല.
